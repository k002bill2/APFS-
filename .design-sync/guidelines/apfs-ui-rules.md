# APFS UI 규칙 (디자인 결정 요약)

- 도메인 톤: 숲(forest green) 기반, 브랜드 블루/시안은 강조·링크·차트 보조. 라이트/다크 둘 다 지원 — 색은 항상 토큰.
- 선택 컨트롤: on/off '여/부'는 Switch, 배타 선택(개인/법인·신주/구주·예/아니오/해당없음)은 RadioGroup, 독립 복수 선택·그리드 행 선택·권한 매트릭스는 Checkbox. 체크박스 20px·radius 6·1.5px 테두리, 체크 시 brand-blue 배경 + 흰 표식(선택 시 spring 팝).
- 폼 모달: RowFormModal 패턴 — 항목이 6개를 넘으면 2단(wide), 긴 텍스트(설명·비고·운용사·펀드명)는 전체 폭, 컨트롤 높이 38px, 모달 기본 폰트 13.5px, 본문 패딩 46px(헤더·푸터 같은 인셋), 저장 버튼은 SaveButton(loading 상태 자동).
- 리스트 화면: 페이지 헤더 + 카드 헤더(KPI) + 툴바(상세필터·새로고침·엑셀) + AG Grid 표 + 푸터(선택 건수). 행 선택 컬럼은 DS Checkbox, 단일선택 표에는 전체선택 헤더가 없다.
- 읽기전용 명세 팝업: 툴바 명세 버튼 또는 행 더블클릭으로 열림, 금액 단위 토글(원/백만원/억원), 개요 kv 그리드(한글 라벨은 가로 배열), 2단 헤더 재무요약 표.
- 상태 표시: StatusBadge는 색 + 아이콘 + 텍스트 3중 표기(정상 success·주의 warning·경고 danger·진행중 info). 조기경보 알림은 숫자가 아닌 빨간 점.
- 모션: 다이얼로그 열림 280ms 3D 플립, 닫힘 대칭. 체크·라디오 표식은 직접 조작했을 때만 팝. 저모션(OS reduced motion)이면 transform 애니메이션 없음.
- 포커스: 전역 :focus-visible 박스섀도 글로우(shadcn ring 미사용). 아이콘 전용 버튼은 접근 이름 필수.
