자펀드관리

자펀드(투자조합)를 검색·조회하고 심사단계(신청→선정→결성/취소) 생애주기를 처리하는 관리 화면. 대형 다단(2단) 헤더 그리드(약정액·변동약정액·납입액·우선손실충당률). 워크플로우: ＋제안서접수 등록 버튼→신청 행 생성, 행(라디오) 선택 시 그 심사단계에 맞는 작업 버튼이 나타나 실행하면 단계가 전이(신청→선정→결성, 신청·선정→취소). 편집 팝업은 단계별로 다름 — 선정=선정조합 등록/수정, 결성=결성조합 수정(엑셀 전체 항목). 데모 데이터에 4개 심사단계를 모두 포함. 합계는 데이터에 맞춰 자동 계산.

합계 -- -----

설계 메모: 구조도 v1.4 기준 — v1.4에서 각 셀렉트박스의 공통코드(CDTP) 매핑이 확정되어, 종전 ⚠검토필요 예시값을 실제 코드값으로 교체함.

계정구분=CDTP:AG(농식품투자계정·농안기금·수산투자계정·FTA·해당사항없음), 자펀드구분/조합구분=CDTP:FG(농림수산식품투자조합·사모투자전문회사·중소기업창업투자조합·한국벤처투자조합·벤처투자조합·신기술사업투자조합), 조합성격=CDTP:FC(46종, 예 사업화(Step-up)·그린바이오·스마트농업 …), 납입방식=CDTP:PT(일시납·분납·수시납), 조합상태=CDTP:FS(운영중·청산중·청산완료), 결성여부=CDTP:MY(미결성·결성·취소). 코드가 아닌 담당자는 동적 사용자 데이터라 ⚠마커 유지. — 구조 유지: v1.2 중복행(약 149행/3벌) 오류는 v1.3에서 51행 1벌로 확정, 본 목업도 1벌 반영.

모펀드는 다중모펀드 옵션 ON 가정(단일=표시, 1개 초과 시 무조건 표시). 사업연도(년도→연도)·등록일시·기준일=날짜 picker. 약정액·변동약정액·납입액·우선손실충당률은 2단 헤더(엑셀 J열). 자펀드관리 프로그램=4화면: 메인 + 제안서접수 등록 팝업 + 선정조합 등록 팝업 + 결성조합 수정 팝업(엑셀 전체 항목).

워크플로우(공고관리 컨텍스트 액션 패턴): 심사단계 셀은 상태 표시 전용(직접클릭 금지), 행(라디오) 선택 시 목록바에 그 단계의 가능한 작업이 등장 — 신청→[선정조합 등록][신청취소], 선정→[결성 확정][수정][선정취소], 결성→[수정](결성조합 수정 팝업), 취소→작업없음. 각 작업은 실제로 단계를 전이하고 목록·합계를 갱신(목업 데모). ＋제안서접수 등록 저장 시 신청 단계 행이 신규 추가. 자펀드 필터=결성 행만(결성돼야 자펀드 등재). 담당자=양한솔·이성훈(엑셀 예시). 데모 데이터는 4개 심사단계(신청·선정·결성·취소)를 모두 포함.

심사단계=신청·선정·결성·취소(업무 생애주기)로 결성여부(CDTP:MY)와 별개. 편집 팝업이 있는 관리화면이라 단위전환 토글은 규칙상 미적용. 넓은 표는 가로 스크롤. 샘플 데이터(도메인 정합: 배분은 납입 전제).
