조회기준
연도별 투자현황 단위: 백만원 · 조합수(개) · 투자배수(배)
연도별 약정·납입·투자자산·회수·투자배수 현황
구분 선정년도 조합수 약정총액 모태펀드약정액 납입총액(A) 모태펀드납입액 현금성자산(B1) 투자자산잔액(B2) 기배분액(C) 회수금 수익 투자배수
(B1+B2+C)/A

* 현금성자산 = 미투자자산의 금융상품
* 결성년도 집계기준은 조합정보의 등록일을 기준으로 Sorting
* 기배분액은 세전을 나타냄(수익배당(세후)+원천징수)

설계 메모: 기준일은 년월 선택기(picker)(셀렉트 금지 규칙), 계정구분=필터 셀렉트, 조회기준=집계축 라디오(선정/결성년도). 13열 넓은 표는 가로 스크롤 컨테이너+구분열 sticky로 본문 안 밀림. AS-IS 금액 단위는 원 → TO-BE 백만원 환산(확정 필요). 샘플 데이터(2011은 원본값 환산).
