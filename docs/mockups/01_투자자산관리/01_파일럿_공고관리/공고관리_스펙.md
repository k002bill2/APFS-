## 0. 확정 설계 결정 (2026-08-23)

| 주제 | 결정 |
|---|---|
| **채택 방향** | **모던 필터형(1b)** — 필터칩 + 행 클릭 선택 + 컨텍스트 액션 + 상태 태그. (전통 관리자형 1a는 참고안 보관) |
| **내비게이션** | **GNB(상단 글로벌)·LNB(좌측 로컬) 사용자 옵션 전환형** — 콘텐츠 영역 공통 |
| **첨부파일** | **드래그앤드롭 + '파일 선택' 버튼** 병행 (KWCAG 2.2 SC 2.5.7 드래그 대체수단 충족) |
| **그리드 CRUD** | 등록/수정/삭제 **버튼화**, 삭제는 **확인 다이얼로그** |
| **폼 재사용** | 등록/수정 = **단일 폼 create/edit 2모드** |
| **용어 표준화** | `사업년도→사업연도`, `계정→계정구분`(모펀드 구성 계정: 농식품투자/수산투자) 적용(용어집 연계) |
| **날짜 컴포넌트** | 년도·일자·분기·반기 = **날짜 선택기(picker)**, 셀렉트박스 금지. 조회 표시만 포맷 라벨 |
| **그리드 솔루션** | IBSheet8 vs AG Grid **검토중**(별도 문서), 미확정 |

**목업**: `mockup\공고관리_목업_artifact.html` (Artifact 발행, 라이브 렌더)

## 1. 화면 ① 공고관리 (목록) — 메인 · 모던 필터형

### 1.1 와이어프레임

```
┌ [GNB] 투자자산관리시스템   모태펀드 · 자펀드 · 보고서        관리자 ┐
├ [서브탭] 공고관리 | 출자사업관리 | 자펀드관리 ───────────────────┤
│  공고관리   출자사업 계획공고 조회·등록·수정·삭제   〔+ 공고문 등록〕│
│  ─ 필터 ─ [모펀드: 농식품모태펀드] [사업연도 2026 ▾] (전체)(정기)(수시) │
│  ┌─────────┬─────────┬────┬──────────┬────────────────────┐ │
│  │사업연도 │정기/수시│차수│계정구분│ 제목               │ │
│  ├─────────┼─────────┼────┼──────────┼────────────────────┤ │
│  │ 2026    │ [정기]  │ 1  │ 농식품   │ …2025년 정기… [PDF] │ ← 클릭 선택
│  └─────────┴─────────┴────┴──────────┴────────────────────┘ │
│   행 선택 시 →  1건 선택  〔수정〕〔삭제〕                     │
└──────────────────────────────────────────────────────────┘
* 내비게이션 옵션 = LNB 좌측형 선택 시: 상단 GNB 대신 좌측 사이드바로 전환
```

### 1.2 필터 영역

| 항목 | 컴포넌트 | 옵션/타입 | 샘플 | 비고 |
|---|---|---|---|---|
| 모펀드 | 필터칩(고정) | 공통코드 **MF**(거래처코드) | 농식품모태펀드 | 사실상 단일값 |
| 사업연도 | **날짜 선택기(연도 picker)** | `YYYY` | 2026 | 셀렉트 금지·날짜=picker. 표준어 사업연도 |
| 정기/수시 | 필터칩 | 전체·정기·수시 | | 칩 토글 |

### 1.3 [섹션1] 목록 그리드

| 컬럼 | 컴포넌트 | 샘플 | 비고 |
|---|---|---|---|
| 사업연도 | 라벨 | 2026 | |
| 정기/수시 | 상태 태그 | 정기 | 정기=파랑 / 수시=주황 |
| 차수 | 라벨 | 1 | |
| 계정구분 | 라벨 | 농식품 | 모펀드(농식품모태펀드) 구성 계정: 농식품투자·수산투자. **자펀드 아님** |
| 제목 | 라벨(+PDF 칩) | 농림수산식품모태펀드 2025년 정기 출자사업(농식품 계정) 계획 공고 | 첨부 있으면 PDF 칩 |

- **행 선택**: 행 클릭 또는 키보드(Enter/Space). 선택 시 `수정`·`삭제` 컨텍스트 버튼 노출.
- **액션**: `+ 공고문 등록`(상시), `수정`/`삭제`(선택 시). 삭제는 확인 다이얼로그.

## 2. 화면 ②③ 공고문 폼 (등록/수정) — 팝업 · 단일 폼 2모드

> 등록=빈 폼(create), 수정=선택 행 프리필(edit). **동일 필드셋, 단일 컴포넌트 2모드.**

```

│  사업연도    : 2026                    (읽기전용)  │
```

> **키(PK) 필드**: 모펀드·사업연도·정기/수시·차수·계정구분. **등록 시 키 조합 중복 체크 필수**, **수정 시 키 필드 잠금(읽기전용)**.

| 항목 | 컴포넌트 | 타입/옵션 | 필수 | 비고 |
|---|---|---|---|---|

| 사업연도 | **등록=날짜 선택기(연도 picker)** / 수정=라벨(읽기전용) | `YYYY` | * | 날짜=picker(셀렉트 금지)·전체 연도 범위(농금원 초기~). 키라 수정 시 잠금·등록 중복체크 |

| 제목 | 인풋박스 | 문자 | * | |
| 공고내용 | 텍스트에어리어 | 문자 | | |
| 첨부파일 | **드래그앤드롭 + 파일선택 버튼** | PDF/HWP/DOCX ≤20MB | | KWCAG 2.5.7 대체수단. **첨부 목록은 드롭존 밖 하단 별도 영역** |

## 3. 내비게이션 옵션 (GNB / LNB)

| 방식 | 구성 | 용도 |
|---|---|---|
| **GNB 상단형** | 상단 글로벌 내비 + 서브 탭 | 넓은 콘텐츠, 얕은 depth |
| **LNB 좌측형** | 좌측 사이드바 로컬 내비 | 메뉴 많고 깊은 depth, 업무형 |

- 사용자 옵션으로 실시간 전환. 콘텐츠(필터·그리드·폼)는 동일.

## 4. 웹접근성 (KWCAG 2.2) — 필수 반영

1. 그리드 행 선택: 키보드(Enter/Space) 조작 가능, 선택 상태 `aria-selected`.
2. 팝업: `role=dialog` `aria-modal` `aria-labelledby` + **포커스 트랩** + **ESC 닫기** + 포커스 복귀.
3. 삭제 확인: `role=alertdialog`, 기본 포커스=취소.
4. 첨부: 드래그앤드롭 + **키보드 조작 '파일 선택' 버튼**(SC 2.5.7).
5. 테이블: 시각적 숨김 `caption` + `th scope`. 토스트 `aria-live=polite`.
6. **모달 오픈 시 배경 스크롤 잠금 + 스크롤바 폭 보정**(레이아웃 시프트 방지).
7. 명도대비 AA, `:focus-visible`, `prefers-reduced-motion`, 라이트/다크 양쪽.
