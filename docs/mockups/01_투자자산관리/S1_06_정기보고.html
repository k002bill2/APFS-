정기보고

운용사가 제출한 자펀드 정기보고서(월간/반기 등)를 검색·조회하는 목록 화면. 기준년월은 월(YYYY-MM) 범위 선택기. "보고구분"의 월간보고서 태그 또는 "상세조회" 클릭 시 개별 보고서 상세 화면(S1_06_01_월간보고.html, 펀드개요·투자진행·미투자자산·수입/비용·누적분배)으로 이동. "보고서" 열은 첨부파일명 표시일 뿐 클릭 이동 없음.
