설계 메모: 금액단위 토글을 검색조건에서 목록 우측 상단(listbar)으로 이동, 명칭도 "원단위"→"금액단위"로 정정(다른 화면들과 통일). 사용자 제공 실 화면 캡처 확인 결과 맨 끝에 연번 열이 추가로 존재 — 소계·합계 행까지 포함해 전체 행을 처음부터 끝까지 순서대로 매기는 일련번호(예: 6행+소계 1행=연번 1~7, 다음 그룹 9행+소계=연번 8~17)로 반영.

[개발자 확인 필요] 같은 캡처에서 그리드가 사업분야별로 그룹화돼 그룹마다 자체 소계(투자금액·회수실적 등)를 갖고, 맨 아래 전체 합계가 또 별도로 있는 구조임을 확인했는데, 지금 목업은 샘플 1건 + 전체 합계 1행뿐이라 이 그룹/소계 구조가 전혀 반영 안 돼 있음. 실 데이터도 캡처에 보이는 것만 20건 이상이라 규모가 상당히 큼 — 그룹별 소계 구조까지 갖춰 전면 재구성할지, 지금처럼 단일 예시만 유지할지 확인 필요.
