설계 메모: 검색조건(모펀드·계정구분·담당자·자펀드·출자/배분·기준일자)은 실제 화면 캡처 기준으로 반영(원문 엑셀엔 [검색] 영역 미정의였으나 확인됨). 안내문구(O열)는 원문에 없어 임의로 넣지 않음. 화면은 조회 목록 + 일자별출자배분관리 상세(드릴다운 모달) 복합.

[사용자 지시, 2026-09-04] 상세 모달에 첨부파일 업로드 기능이 원문에 없음을 확인 — 드래그앤드롭·파일선택 UI와 "저장" 버튼을 제거하고, 읽기전용 "업로드 여부" 항목만 남긴 뒤 "닫기" 단일 버튼으로 정리(더 이상 입력 폼이 아니므로, 금액 단위전환 토글 미적용 방침은 재검토 필요 — 아래 [확인 필요] 참고). 기타조합원·모태펀드 배분은 2단 헤더(엑셀 J열). 도메인 정합: 납입(A)>0·회수/수익 미발생이라 배분(C)=0. 근거 없는 코드/데이터는 생성하지 않고 검토필요(⚠)로 표기.

[개발자 확인 필요] 검색조건 담당자가 어느 쪽 담당자를 의미하는지 원문에 명확하지 않음 — 출자자(LP) 측 담당자인지, 운용사(GP) 측 담당자인지 확인 필요. 목록에 없는 값이라 추정할 근거가 없어 개발자에게 직접 문의 필요.

[확인 필요] 상세 모달이 이제 입력 폼이 아니라 읽기전용이 됐으므로, 메인 그리드·모달의 금액 단위전환(원/백만원/억원) 토글을 다시 붙여야 하는지 확인 필요.
