자펀드수탁관리(확정)

운용사(GP) 보유내역과 수탁기관 보유내역을 대사(對査)해 일치여부를 판정하고 확정 처리하는 화면. 기준일자로 조회하면 전체 자펀드의 대사 목록이 나오고, 자펀드별 항목(투자자산·미투자자산 거래·미투자자산) 일치여부를 확인하며 [일치/불일치] 상세를 열어 3개 섹션의 대사 내역을 비교한다.

자펀드수탁관리(확정)

총 24건(실 화면 캡처 기준 발췌 — 전체 약 152건 중 24건)
자펀드 수탁 대사 목록 — 일치여부는 투자자산·미투자자산 거래·미투자자산으로 나뉜 다단 헤더
No 운용사 자펀드 일치여부 상세보기 확정여부
투자자산 미투자자산 거래 미투자자산
보유주수잔액 보유주수잔액 잔액

설계 메모: 검색조건은 실 화면 캡처 기준 기준일자 단일 필드만 존재(운용사·자펀드·확정여부 필터 없음 — 이전에 있던 3개 필드와 검토필요 마커는 제거). 목록은 원래 전체 자펀드(약 152건)를 보여주는데, 이 목업엔 실 캡처로 정확히 읽은 24건만 발췌 반영(나머지는 임의 생성하지 않음). 확정여부는 셀렉트로 "확정"·"미확정" 2개 실값 확인(불일치 건은 미확정, 일치 건은 확정 — 캡처에서 관찰된 패턴). 상세보기 팝업은 원 구조도 상세 예시 1건(요즘주방 등)을 그대로 재사용 — 24건 각각의 실제 상세 수치는 목록 화면만으로는 확보 불가(검토필요 표시).
