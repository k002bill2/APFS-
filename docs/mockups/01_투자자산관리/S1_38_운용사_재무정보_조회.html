설계 메모: 사용자 제공 실 화면 캡처(2026-08-28, 기준년월 2026-01) 기준 전면 재구성 — 기존엔 운용사 1개를 셀렉트로 골라 재무상태표·손익계산서 2개 카드로 나눠 보여주는 단일 상세뷰였는데, 실제로는 운용사명·GP구분·기준년월 + 재무상태표·손익계산서 항목 전체를 한 행에 나열한 그리드였음(카드 분리·항목 그룹핑 추론 마커는 실제 구조 확인으로 해소). 운용사 입력은 GP코드+GP명 텍스트 필드와 G.P 검색 팝업(검색어 입력 → 결과 목록 클릭 시 선택)으로 구성.

[개발자 확인 필요] 캡처엔 운용사=NH투자증권으로 조회했는데 결과 그리드엔 NH투자증권(증권회사)·농협은행(은행) 2건이 함께 나옴 — 운용사 필터가 실제로 결과를 좁히는지, 아니면 기준년월 전체 운용사 목록을 항상 보여주는 화면인지 확인 필요. 기준년월 셀은 캡처상 파란 링크 — 클릭 시 운용사 정량지표 상세(재무건정성비율) 팝업이 이 화면 위에 뜨도록 구현(사용자 지시, 2026-08-28). 원래 이 팝업 내용은 별도 서브메뉴 화면(S1_39_운용사정량지표상세_재무건정성비율_.html)이었는데, 독립 메뉴로 두지 않고 이 화면의 팝업으로 흡수하기로 해서 S1_39 파일은 삭제하고 subtab·LNB의 해당 항목도 모니터링 그룹 전체(S1_38~S1_45)에서 제거함. 팝업 내용은 사용자 제공 실 화면 캡처(BNK벤처투자(주) 예시)로 재확인 — 운용사명·GP구분·지표명(재무건정성비율(단위:%)) 3행 표 + "조회내용이 없습니다." 한 줄로 끝나는 단순 구조가 실제 그대로였음. 재무건정성비율 값 자체가 시스템에 비어있는 게 캡처로 확인된 실제 상태라 더 이상 추정이 아니므로 검토필요 마커는 제거하고 실제 빈 상태 문구를 그대로 반영.

[대표님과 논의 필요] 이 화면의 운용사 필터가 다른 화면들과 달리 셀렉트박스가 아니라 코드+명칭 텍스트 입력 + 별도 검색 팝업 방식으로 돼 있음 — 실 화면 캡처가 이렇게 돼 있어 그대로 반영했지만, 프로젝트 전체적으로 통일된 셀렉트박스 방식으로 바꿀지 이 화면만 검색 방식을 유지할지 논의 필요.
