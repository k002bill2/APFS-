공통코드

총 1건
코드구분 '유형분류'에 속한 공통코드 목록 — 코드·코드명·비고
코드 코드명 비고

설계 메모(2026-08-31, 엑셀 반영): 검색조건 코드구분이 원문 M열에 9종(해외기업고유번호·트랜잭션구분·자산분류·유형분류·거래유형·거래상세유형·거래구분·매입매도구분·종목구분)으로 확정돼 있어 플레이스홀더 마커를 걷어내고 실제 옵션으로 전면 반영, 기본 선택값은 원문 P열대로 유형분류. 코드구분 선택에 따라 그리드가 바뀌는 동적 관계를 실제로 구현(LISTS 객체 + 확인 버튼) — 단 엑셀에 확정 실데이터가 있는 유형분류(A1/CALL) 1건만 표시하고, 나머지 8개 코드구분은 원문 샘플이 없어 빈 상태로 표시(임의 코드 생성 안 함). 참고: 유형분류 코드값(A1=CALL 등)은 같은 시스템의 실물자료 조회(월별) 화면 중분류 목록과 동일 체계로 보이나, 이 화면 자체의 확정 데이터는 A1/CALL 1건뿐이라 나머지 항목을 임의로 끌어와 채우지 않음.
