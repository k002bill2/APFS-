총 1건
모태수탁공통코드 목록 — 선택한 코드구분(거래구분)의 코드·코드명·비고
코드 코드명 비고

설계 메모(2026-08-31, 엑셀 반영): 검색조건 코드구분이 원문 M열에 7종(거래구분·입출금구분·계좌계정구분·계좌구분·계좌종류·기타거래처코드·금융기관코드)으로 확정돼 있어 플레이스홀더 마커를 걷어내고 실제 옵션으로 전면 반영, 기본 선택값은 원문 P열대로 거래구분. 코드구분 선택에 따라 그리드가 바뀌는 동적 관계를 실제로 구현(LISTS 객체 + 확인 버튼) — 단 엑셀에 확정 실데이터가 있는 거래구분(A1/모태출자금/입금성격) 1건만 표시하고, 나머지 6개 코드구분은 원문 샘플이 없어 빈 상태로 표시(임의 코드 생성 안 함). 날짜·금액 항목이 없어 picker·단위전환 토글 미적용. 읽기 전용 참조 화면이라 등록/수정 폼·팝업 없음('확인'=조회). 검토필요 마커는 모두 해소되어 제거.
