설계 메모(2026-08-31, 엑셀 반영): 사용자가 엑셀에 추가한 검색조건 조합(운용사 하위 셀렉트박스)을 신규 반영 — 기존 "운용사/조합" 통합 필드를 원문대로 운용사·조합 2개 필드로 분리.

대분류·중분류는 원문 M열에 코드 목록이 확정돼 있어 플레이스홀더 마커를 걷어내고 실제 옵션 목록으로 반영(대분류 8종, 중분류 15종). 반영 중 원문 오류 2건 확인:
① 중분류 "A9]기타"에 여는 대괄호가 누락돼 있어 "[A9]기타"로 정정(주황).
② 대분류 5번째 코드가 "[티]프로젝트투자"로 돼 있어 A·B·C·D·F·G·H 순서상 [E]의 오기로 추정되나 확정 근거가 없어 원문 그대로 표기하고 검토필요로 표시. 엑셀 A열(No)은 신규 조합 항목에 이어 번호 부여 후 이후 전체 행 +1 재넘버링(통합 시트 2761행 이후~시트 끝).

[2차 반영] 사용자가 엑셀에 [섹션1]그리드 자체가 비어있던 것을 확인해 실제 컬럼 정의와 실데이터 1건을 신규 채워넣음(체크박스·수탁기관·기준년월·순번·자산분류(대분류)·유형분류(중분류)·조합명·종목명·종목코드·사업자번호·계좌번호·잔여주수·보유잔액·이자, 14개 항목, 통합 시트 2770~2783행) — 기존에 원문 근거 없이 추론으로 채워뒀던 가짜 목록(대분류·중분류·파일명·형식·크기·등록자·등록일시)을 전부 걷어내고 실제 그리드로 재구성. 체크박스 컴포넌트에 맞춰 행 선택도 라디오(단일선택)→체크박스(다중선택)로 정정. 계좌번호·잔여주수·보유잔액·이자는 원문 P열이 공란이라 "-"로 표시(임의값 미생성). 자산분류·유형분류 코드는 검색조건에서 이미 확정된 enum과 매핑해 괄호 안에 한글명 병기(예: "B (채권)").
