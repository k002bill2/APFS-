총 1건 · 평가년월 2025-12
금액 단위
투자조합 가치평가 결과 목록 — 금액 열은 선택한 단위로 환산 표시
평가년월 결성년도 자펀드 GP명 결성총액 납입총액 누적투자금액 투자원금잔액 조합운용성과 수익배수 관리등급 투자자산평가 기분배내역 미투자자산 기타자산 기타부채

설계 메모(2026-08-31, 원본 오류 정정 + 검토필요 마커 전부 제거): 그리드 항목명 "기본배내역"이 엑셀 원문 자체의 오타였음을 확인해 "기분배내역"으로 정정(통합 시트 I2444, 주황 음영 — 사용자와 함께 작업하며 정정한 항목이라 주황으로 확정). 화면의 검토필요 마커 4건(자펀드 목록 미확인·결성년도 예시값·관리등급 코드셋 추정·기본배내역 용어확인)을 사용자 지시로 전부 제거 — 마커가 짚던 사항은 이 메모로 갈음: 자펀드 검색조건은 표본(전체+엘앤에스 농수산업 투자조합)을 확정 인정(§2.4 필터 select 표본 인정 규칙).

결성년도는 원문 P열이 공란이라 임의 연도를 넣지 않고 "-"로 표시.

관리등급은 원문 실값 "주의" 1건만 확정 반영. 마커 제거하며 함께 확인한 결과, 그리드에 있던 비교 데모 샘플 2건(아이엠엠 농식품 스마트투자조합·한투 청년농식품투자조합)이 원문에 없는 임의 생성 데이터였음을 발견해 제거 — 엑셀 확정 실데이터는 엘앤에스 농수산업 투자조합 1건뿐임.

[추가 반영] 사용자가 엑셀 [섹션1]그리드에 직접 추가한 미투자자산·기타자산·기타부채 3개 항목(2445-2447행, 주황 음영)을 그리드 컬럼으로 신규 반영(S2_80 모태펀드 가치평가 결과관리의 동일 계열 항목과 순서 일치: 투자자산평가→기분배내역→미투자자산→기타자산→기타부채).

[오타 정정, 2026-08-31] 항목명 "기타부족"이 엑셀 원문 자체의 오타였음을 사용자가 확인 — "기타부채"로 정정(통합 시트 I2447, 주황 음영).

[사용자 지시, 2026-09-03] 용도가 불명확했던 그리드 맨 앞 라디오버튼(행 선택) 열을 삭제 — 읽기 전용 조회 화면에 선택 결과를 사용하는 기능이 없어 불필요 판단.
