메뉴관리

시스템 메뉴 트리를 등록·수정하고 메뉴별 권한을 관리하는 관리자 화면. 좌측 메뉴 목록에서 행을 선택하면 우측 메뉴 상세가 채워지고(수정 모드, 코드 잠금), 추가 시 신규 입력 모드(코드 편집·중복체크)로 전환된다. 하단 권한 그리드는 행추가·행삭제로 편집. CRUD 관리화면이라 금액 단위전환 토글은 규칙상 미적용.
