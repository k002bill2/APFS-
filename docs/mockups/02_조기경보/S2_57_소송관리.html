총 3건
소송 목록 — 선택 체크박스로 다건 선택 후 해제등록·엑셀 처리
No 기준년월 구분 운용사 소송내역 확정구분 소송일자 해제일자

설계 메모:

[확인 필요] "해제"의 정확한 업무적 의미가 원문에 명확히 정의돼 있지 않음(주주변동관리 화면과 동일한 확인 필요) — 해당 소송 건이 종결·정리되었음을 기록하는 상태 전환(이력 유지)인지, 목록에서 완전히 제거하는 처리인지 확인 필요. 현재 목업은 상태 전환(이력 유지)으로 구현돼 있음.

[확인 필요] 등록 팝업의 확정구분(확정/미확정)이 그리드의 구분(등록/해제) 상태와 어떤 관계인지 원문에 명확히 정의돼 있지 않음 — 확인된 바로는 "미확정" 선택 시 이후 "해제" 처리로 이어지는 흐름이 있는 것으로 보이나, "확정" 선택 시에는 어떤 처리·상태 전이가 일어나는지(별도 절차 없이 그대로 유지되는지, 다른 처리로 이어지는지) 확인 필요. 현재 목업 샘플 데이터 3건은 모두 확정=확정이라 미확정 케이스의 실제 동작은 검증되지 않음.

[확인 필요] 목록의 다건 체크박스 선택(멀티체크)이 실제로 필요한 기능인지도 확인 필요 — 해제등록이 여러 건을 한 번에 처리하는 업무가 실제로 있는지, 아니면 건별 단일 처리로 충분한지에 따라 UI를 단순화(라디오 단일선택)할 수도 있음.

주주변동관리 화면도 동일한 구조(멀티체크+해제등록)라 같은 확인이 필요.
