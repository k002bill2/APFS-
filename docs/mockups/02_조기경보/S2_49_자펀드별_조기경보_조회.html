총 1건
자펀드별 조기경보 현황 — 한도관리는 의무투자·일정규모이하투자·투자자산·미투자자산 2단 헤더
No 모펀드 운용사 자펀드 조합성격 자펀드수익률 규약위반 대표펀드매니저변동 운용인력변동 한도관리 종합등급
의무투자 일정규모이하투자 투자자산 미투자자산

설계 메모: 종합등급(자펀드·운용사 공통 조기경보 등급 체계)은 정상·주의·경고 3단계로 확정(원문 AS-IS: 조기경보 조회·시계열 차트·종합등급 변동 화면에 일관 등장, "심각" 단계는 원문에 없음). 태그 색상은 정상=녹색·주의=주황·경고=빨강. 원문 실데이터는 정상·경고 2건만 확인되어 주의 단계 샘플은 없음(임의 생성 안 함).

자펀드수익률 셀을 클릭(또는 Enter/Space)하면 자펀드별 조기경보 상세조회 - 자펀드수익률 팝업이 뜹니다 — 이 화면은 이제 독립 메뉴가 아니라 이 팝업 하나로만 존재(GNB/LNB/서브탭 제외). 팝업 상세 수치는 원문 유일 표본(엘앤에스농식품6차산업화투자조합)을 재사용한 구조 시연용입니다.

[확인 필요] 그리드의 나머지 항목(규약위반·대표펀드매니저변동·운용인력변동·한도관리·종합등급)도 자펀드수익률처럼 셀 클릭 시 별도 상세조회 팝업/화면이 있는지 원문(엑셀 구조도)상 확인되지 않음 — 있다면 자펀드수익률과 동일한 방식(독립 메뉴 아니라 이 화면 위 팝업)으로 흡수해야 하는지 확인 필요.
