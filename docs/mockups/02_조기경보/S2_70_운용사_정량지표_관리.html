운용사 정량지표 관리

총 2건
운용사 정량지표 판정기준 목록 — 운용사구분·지표구분별 정상·주의·경고 기준. 행 클릭 시 수정 팝업
No 운용사구분 지표구분 정상 주의 경고

설계 메모(2026-08-28, 사용자 제공 실제 화면 캡처 반영): 사용자가 제공한 "운용사 정량지표 수정"(증권회사) 실제 화면 캡처를 근거로 지표구분 마스터·수정 팝업을 재확정.

지표구분 7종(영업용순자본비율·유동성비율·자기자본이익률·총자산수익률·자본충실도·부채비율·수익성)으로 교체 — 기존 재사용하던 "부채비율(유동성비율)" 통합표기는 오류였고 실제로는 별개 지표(부채비율/유동성비율)이며, 총자산수익률·수익성은 이번에 처음 확인됨(S2_63 5종 표기와는 별개, 이 화면 계열만 교체). 목록은 사용중인 지표만 평탄화 표시: 벤처투자회사/자본충실도(기존 확정값) + 증권회사 사용중 4건(영업용순자본비율·유동성비율·자기자본이익률·총자산수익률, 캡처 화면 실값).

행 클릭 → 수정 팝업은 해당 운용사구분의 지표 7종 전체 그리드를 로드(엑셀 G열: 운용사구분→수정 팝업 연결). 수정 팝업의 운용사 유형은 캡처 화면처럼 실제 동작하는 셀렉트박스로 전환(선택 시 그리드 갱신), 타이틀 옆 도움말(?) 아이콘 신규 반영(안내문구 미정으로 클릭 시 자리표시 토스트). 캡처 화면에 선택 체크박스 컬럼이 없어 행 클릭 하이라이트 후 행삭제하는 방식으로 변경(등록·수정 팝업 공통). 저장·닫기(타이틀 영역)·행추가/행삭제(하단 영역) 배치는 직전 턴 반영값 유지.

운용사 유형 6종(벤처투자회사·증권회사·여신전문금융회사·자산운용사·은행·보험사)은 S2_71 등록 팝업 확정값 그대로.

입력항목(체크박스) 용도는 원문에 라벨만 있어 검토필요 마커 유지. 증권회사 외 5개 유형은 원문 화면 미제공이라 등록 시 최초상태와 동일한 빈 값으로 표시(검토필요 아님).
