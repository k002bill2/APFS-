설계 메모: 읽기전용 조회 금액화면이라 원/백만원/억원 단위 전환 토글 적용(base=원 저장 후 포맷). 평가년월(YYYY-MM)은 월 선택기(연도 페이징 + 12개월 그리드), 셀렉트박스로 날짜를 만들지 않음.

자펀드 필터는 마스터 미연동·표본 인정 규칙(§2.4)에 따라 실데이터 1건만 표기(검토필요 아님). 도메인 정합: 회수총액=0 → IRR=0.00, 투자잔액=총투자금액-회수총액. 원본에 없는 투자기업·사업자번호는 임의 생성하지 않고 실데이터 1행만 표시. 그리드에 원문에 없던 No 컬럼이 있었던 것을 제거, 검색영역 "엑셀" 버튼이 원문 정의(검색 영역)와 달리 목록 영역 밖에 있던 것을 검색영역 안으로 이동.

[팝업 병합, 2026-08-31] "투자기업별(계약별) IRR 근거"가 별도 메뉴 화면(구 S2_88)으로 만들어져 있었으나 엑셀 원문(F열=팝업, G열=투자기업)을 사용자가 프로그램명 병합으로 확정 — 그리드의 투자기업 셀 클릭 시 열리는 실제 팝업으로 이식하고 별도 메뉴에서 제외. 팝업 그리드 실데이터는 원문 1건(A&F미래성장투자조합·(주)썬리취·CB·2018-10-23·투자·-3,000,000,000)만 존재 — 구 팝업에 있던 이자수취·상환 등 추가 행과 IRR(계산값)은 원문에 없는 임의 생성 데이터라 함께 제거. 팝업 표본 조합·기업명이 상단 그리드 표본(2022 원익 스마트 혁신 Agtech투자조합·셀미트(주))과 다른 것은 오류가 아니라 엑셀이 메인 그리드와 팝업 그리드에 서로 독립된 예시 실데이터를 부여했기 때문(1:1 드릴다운 연결 아님).
