GNB는 조기경보 대메뉴로 확정 매핑. [확인 필요] "수정권한"의 정확한 의미와 범위가 원문에 명확히 정의돼 있지 않음 — 이 권한이 부여되면 운용사가 구체적으로 무엇을(어느 화면·어느 항목을) 수정할 수 있게 되는지, 한 번 부여된 권한이 특정 기간(해당 기준년월 한정)에만 유효한지 계속 유지되는지, 그리고 이 권한 처리가 다른 화면(예: 운용사 재무정보 등록/보고 화면)의 편집 가능 여부와 실제로 어떻게 연동되는지 확인 필요. [확인 필요] 섹션2(운용사 재무정보 보고현황)의 기준년월(2026-06)이 상단 검색조건·섹션1과 같은 기준년월(2026-07)인데도 한 달 차이로 표시됨 — 운용사 재무정보 보고가 원래 전월(-1월) 기준으로 집계되는 게 맞는지(메인화면의 "당월 보고여부(기준월)" 항목과 같은 의문), 아니면 단순 하드코딩 오류인지 확인 필요.
