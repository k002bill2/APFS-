설계 메모(2026-08-28, 등록·수정 팝업 엑셀 재확인 반영): 사용자가 등록·수정 팝업(2274-2315행)을 다시 확인 요청, 재조회 중 원본 엑셀 데이터 오류 발견·정정(노란 음영) — 수정 팝업의 저장/닫기/자펀드/투자기간(2)/결산월 6개 항목의 컴포넌트·값(L~Q열)이 2행 밀려 입력돼 있던 것을 발견해 재정렬(근거: 저장/닫기는 전 화면 공통 버튼, 자펀드 선택값이 실제 조합명, 투자기간 값이 날짜형식, 결산월 값 12가 하단 [섹션2]그리드 결산월 실값과 일치), 팝업 타이틀도 "자펀드 정보 등록"으로 잘못 남아있던 것을 "자펀드 정보 수정"으로 정정.

구조 변경(주황 반영 대상 아님, 원문 그대로 재구성): 저장/닫기를 모달 하단→상단(타이틀 영역)으로 이동. 한도관리[섹션1]은 원문에 행추가/행삭제가 없어 의무투자비율 단일 고정행으로 단순화(이전 턴에 있던 "일정규모이하투자비율" 2번째 행과 그 검토필요 마커는 원문에 없는 항목이라 제거 — 해당 값은 메인 그리드의 별도 "일정규모이하투자" 컬럼으로 이미 존재함).

운용사[섹션2]는 읽기전용 단일행이 아니라 행추가/행삭제가 있는 관리형 그리드였음을 확인 — 대표여부·운용사·사업자번호·운용사구분·결산월·보고운용사코드 6개 필드로 재구성(공동GP 자펀드는 여러 운용사 행을 가질 수 있음, 메인 그리드의 "공동GP여부" 컬럼과 연결되는 개념).

자펀드 선택은 원문 컴포넌트가 등록/수정 모두 셀렉트박스로 동일해 수정에서도 잠금(readonly) 대신 실동작 셀렉트로 구현(이전 턴의 PK잠금 처리는 원문과 달라 제거). 수정 팝업 실데이터는 세종농식품R&D사업화투자조합(투자기간 2014-07-21~2017-07-20·3년, 결산월 12, 운용사 로이투자파트너스 주식회사·사업자번호 220-88-59914·벤처투자회사·보고운용사코드 GBBLIB) 그대로 확정 반영. 메인 그리드 행 클릭 시엔 해당 행이 가진 값(비율·기간·운용사)만 채우고 결산월·사업자번호 등 메인 그리드에 없는 항목은 빈 값으로 시작(별도 화면 S2_75 참조 시 전체 확정값 확인 가능).
