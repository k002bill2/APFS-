[팝업 병합] "투자기업별 IRR 근거"가 별도 메뉴 화면(구 S2_92)으로 만들어져 있었으나 엑셀 원문(F열=팝업, G열=투자기업)을 사용자가 프로그램명 병합으로 확정 — 그리드의 투자기업 셀 클릭 시 열리는 실제 팝업으로 이식하고 별도 메뉴에서 제외. 팝업 실데이터는 원문 1건(AJ-ISU경기도애그리푸드투자조합·(주)프레시지·우선주·2020-07-30·투자·-1,499,957,210)만 존재 — 구 팝업에 있던 추가 투자·회수·배분 행(3건)은 원문에 없는 임의 생성 데이터라 함께 제거. 팝업 표본 조합·기업명이 상단 그리드 표본과 다른 것은 엑셀이 메인 그리드와 팝업 그리드에 서로 독립된 예시 실데이터를 부여했기 때문(1:1 드릴다운 연결 아님).
