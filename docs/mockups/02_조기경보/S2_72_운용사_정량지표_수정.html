운용사 정량지표

총 4건 (운용사 유형: 증권회사 · 사용중인 지표만 표시)
운용사 정량지표 목록 — 운용사 유형 증권회사
No 사용 지표구분 정상 주의 경고 입력항목
1 사용 영업용순자본비율 400 이상 150 이상 150 미만 사용
2 사용 유동성비율 100 이상 50 이상 50 미만 사용
3 사용 자기자본이익률 -5 이상 -10 이상 -10 미만 -
4 사용 총자산수익률 -5 이상 -20 이상 -20 미만 -

설계 메모(2026-08-28, 사용자 제공 실제 화면 캡처 반영): 사용자가 제공한 "운용사 정량지표 수정"(증권회사) 실제 화면을 근거로 팝업을 전면 재구현.

① 지표구분 마스터가 7종(영업용순자본비율·유동성비율·자기자본이익률·총자산수익률·자본충실도·부채비율·수익성)으로 확정 — 기존에 재사용하던 "부채비율(유동성비율)" 통합표기는 오류였고 실제로는 별개 지표 2개(부채비율, 유동성비율)이며, 총자산수익률·수익성은 이번에 처음 확인됨(S2_63 5종 목록과 불일치 — S2_63은 별도 확인 전까지 미변경, 이 화면 계열(S2_70~72)만 7종으로 교체).

② 증권회사의 지표별 사용여부·정상/주의/경고 기준·입력항목 체크상태를 화면 캡처 값 그대로 확정 반영(영업용순자본비율 400/150/150, 유동성비율 100/50/50, 자기자본이익률 -5/-10/-10, 총자산수익률 -5/-20/-20 = 사용중 4건, 자본충실도·부채비율·수익성 = 미사용 3건). 증권회사 외 5개 유형은 원문 화면 미제공이라 전 지표 미사용·기준값 없음(검토필요 아님 — 등록 시 최초 상태와 동일한 빈 값이므로).

[확인 필요] 증권회사가 아닌 "정상"(기본/그 외) 상태일 때도 동일한 지표구분 7종 마스터·입력항목 구성이 실제로 맞는지 확인 필요 — 현재는 증권회사 캡처 1건만 실증됐고, 나머지 5개 유형도 같은 지표 세트·같은 입력항목 컴포넌트를 쓰는지는 원문으로 검증되지 않음(유형별로 지표 종류·항목 자체가 다를 가능성 있음).

③ 캡처 화면에 선택 체크박스 컬럼이 없어 이전 턴에 추가했던 선택 컬럼·전체선택 헤더를 제거하고, 행 클릭으로 선택 하이라이트 후 행삭제하는 방식으로 변경.

④ 운용사 유형을 캡처 화면처럼 실제 동작하는 셀렉트박스로 변경(선택 시 해당 유형의 지표 그리드로 갱신) — 이전 턴의 읽기전용 잠금은 캡처와 달라 제거.

⑤ 타이틀 옆 도움말(?) 아이콘 신규 반영(원문 O열에 안내문구 정의가 없어 클릭 시 자리표시 토스트만 표시). 저장/닫기(타이틀 영역)·행추가/행삭제(하단 영역) 배치는 직전 턴 반영값 유지.

입력항목(체크박스) 용도는 여전히 원문에 라벨만 있어 검토필요 마커 유지.
