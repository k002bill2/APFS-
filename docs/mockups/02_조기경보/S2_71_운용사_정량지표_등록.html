설계 메모(2026-08-28, 수정 팝업 구조로 통일): 등록·수정 팝업이 서로 다른 CSS/마크업 구조로 따로 작성돼 있던 것을 수정 팝업(S2_72, 실제 화면 캡처 기준)의 구조로 통일 — 그리드 클래스를 `mgrid`(모달 전용) → `grid`(수정 팝업과 동일 클래스), 헤더의 상태점 아이콘·노출형 caption·안내문구 span 제거(수정 팝업엔 없던 요소), 캡션을 시각적으로 숨김 처리, 컬럼 너비·정렬을 수정 팝업과 동일하게(정상/주의/경고 가운데정렬), 모달 폭 820px→720px(수정 팝업과 동일), 타이틀 옆 도움말(?) 아이콘 추가.

지표구분 마스터 7종(영업용순자본비율·유동성비율·자기자본이익률·총자산수익률·자본충실도·부채비율·수익성, 수정 팝업 캡처 근거)은 이전 반영 유지.

입력항목만 등록=인풋박스 / 수정=체크박스로 원문 컴포넌트 차이를 그대로 유지(엑셀 2238행·2250행 컴포넌트 정의가 서로 다름 — 구조 통일 대상이 아닌 의도된 차이). 캡처 화면에 선택 체크박스 컬럼이 없어 행 클릭으로 선택(하이라이트) 후 행삭제하는 방식(수정 팝업과 동일 동작). 저장·닫기 버튼은 모달 상단(타이틀 영역), 행추가·행삭제는 그리드 하단 영역 — 새로 추가되는 행은 지표구분을 표시할 근거값이 없어 직접입력 형태로 구성(추론, 데이터 발명 아님). 등록(신규 입력) 팝업이라 정상·주의·경고 라벨은 빈값(–)으로 시작.

[확인 필요] 증권회사가 아닌 "정상"(기본/그 외) 상태일 때도 동일한 지표구분 7종 마스터·입력항목 구성이 실제로 맞는지 확인 필요 — 현재는 증권회사 캡처 1건만 실증됐고, 나머지 5개 유형도 같은 지표 세트·같은 입력항목 컴포넌트를 쓰는지는 원문으로 검증되지 않음(유형별로 지표 종류·항목 자체가 다를 가능성 있음).
