선택 No 상위코드 코드 코드명 비고

설계 메모: AS-IS는 코드(코드그룹)·코드상세 2단 마스터-디테일 구조. 좌측 코드그룹 선택 → 우측 상세 연동(엑셀엔 관계 미표현, TO-BE 반영). PK인 코드는 §2.2 표준대로 신규행만 편집·중복체크, 기존행은 잠금(🔒). 실 샘플: 코드그룹 FINAL_TPCD/확정구분, 상세 CREAT_CD·01/운용사지표결과정보/EWRS036. CREAT_CD는 상세의 상위코드로만 등장(코드명 원천 없음) → 검토필요 표시. 편집(CRUD) 관리화면이라 금액 단위전환 토글 미적용, 첨부·검색필터·안내문구는 원천에 없어 생성하지 않음.
