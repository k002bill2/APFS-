설계 메모(2026-08-28, 사용자 제공 실제 화면 캡처 반영): 사용자가 제공한 "자펀드 정보 등록" 실제 화면 캡처를 근거로 재구현.

① 투자기간을 "투자기간(년)"과 "투자기간"(날짜범위)으로 나눠 2개 행으로 표시하던 것을 캡처 화면대로 한 행에 [년 숫자입력]+[시작일]~[종료일] 형태로 병합.

② 결산월 셀렉트 옆에 "월" 단위 텍스트 추가.

③ 한도관리[섹션1]·운용사[섹션2] 그리드 모두 캡처 화면처럼 등록 시 빈 상태("조회 내역이 없습니다")로 시작 — 이전 턴에 넣었던 한도관리 기본 1행, 운용사 기본 1행은 캡처와 달라 제거(운용사는 행추가로 직접 추가).

④ 운용사 그리드에 선택 체크박스 컬럼이 없어(캡처 확인) 행 클릭으로 선택(하이라이트) 후 행삭제하는 방식으로 변경.

⑤ 타이틀 옆 도움말(?) 아이콘 신규 반영(안내문구 미정으로 자리표시 토스트만). 저장/닫기(타이틀 영역)는 이전 턴 반영값 유지. 등록형 팝업이라 단위전환 토글 미적용.
