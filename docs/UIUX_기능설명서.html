개요

농림수산식품모태펀드 투자자산관리시스템(APFS) 대시보드 프로토타입에 지금 구현돼 있는 화면과, 각 화면에서 사용자가 할 수 있는 일을 정리한 문서다. 현업·PM이 화면별 기능 범위를 확인하는 용도로 쓴다. 파일 경로·폴더 배치는 페이지 구성과 docs/filetree.md를 본다.

프로토타입 전제

  • 백엔드가 없다. 모든 값은 화면에 넣어 둔 목업·더미 데이터다.
  • 등록·수정·삭제·확정 같은 변경은 그 화면을 보는 동안만 유지되고, 새로고침하거나 다른 화면에 다녀오면 원래 데이터로 돌아간다.
  • 로그인·권한 판정·메일 발송·파일 전송은 실제로 하지 않는다. 버튼을 누르면 결과 안내(토스트)만 보이는 곳은 화면 카드에 데모로 표시했다.
  • 브라우저에 저장되는 것은 테마, 메뉴 접힘, 화면 폭, 마지막으로 연 화면, 즐겨찾기, 방문기록, 즐겨찾기 버튼 위치뿐이다.

공통 화면 골격

로그인·온보딩·월간보고 창을 뺀 모든 화면은 같은 틀(상단 GNB + 왼쪽 LNB + 본문) 안에서 열린다.

상단 바(GNB)

  • 왼쪽부터 메뉴 접기/펴기 버튼, 로고(다크 테마에선 흰 로고), 시스템명.
  • 검색 상자 '메뉴·운용사·자펀드 검색' → 명령 팔레트. 전체 메뉴를 대분류별로 묶어 이름·중분류로 찾고, 고르면 바로 이동한다. 실제로 찾는 대상은 메뉴뿐이다(운용사·자펀드 데이터 검색은 아직 없음).
  • 오른쪽: 고정 너비/전체 너비 전환, 라이트/다크 전환, 알림(안 읽은 개수 배지), 사용자 메뉴(김정원 · 투자운용본부).
  • 사용자 메뉴: 메모 · 일정 · 로그아웃. 각각 모달로 열린다. 로그아웃은 확인 모달만 있고 실제로 로그아웃하지 않는다 데모

왼쪽 메뉴(LNB)

  • 3단계 트리(대분류 → 중분류 → 화면). 중분류는 처음부터 펼쳐져 있고, 지금 화면의 상위 그룹은 자동으로 열리며 해당 화면이 강조되고 보이는 위치로 스크롤된다.
  • 접힌 상태(아이콘만, 66px): 아이콘에 마우스를 올리거나 포커스 후 Enter → 옆으로 하위 메뉴 패널이 열린다.
  • 조기경보 새 항목은 숫자가 아니라 빨간 점으로 표시한다(조기경보 대분류 · 조기경보 중분류 · '조기경보 결과정보 관리'). 다른 메뉴에는 점이 없다.
  • 맨 아래: 디자인 시스템 바로가기, 보안 접속 상태(내부망 · TLS 1.3 — 고정 문구).
  • 폭 760px 이하(모바일)에서는 메뉴 버튼으로 여닫는 서랍이 되고, 화면을 옮기면 자동으로 닫힌다.

페이지 머리

  • 위치 경로(홈 › 대분류 › 중분류 › 화면)와 오른쪽 방문기록 버튼. 방문기록은 최근 30개(지금 화면 제외)를 보여주고 [지우기], Esc로 닫는다.
  • 리스트 화면은 카드 머리에 화면 제목과 ★(즐겨찾기 추가/해제), 오른쪽에 KPI 배지가 붙는다.

즐겨찾기 버튼(오른쪽 아래 ★)

  • 누르면 즐겨찾기 목록이 열리고, 항목을 누르면 이동한다. 기본값은 모태펀드 조성 및 출자현황 · 조기경보 관리 · 자펀드 공고 정보관리.
  • ⚙ → 즐겨찾기 편집: 전체 메뉴를 대분류·중분류별 칩으로 켜고 끈다. 개수 제한 없음, [기본값으로 초기화].
  • 버튼을 끌어서 옮길 수 있고 위치는 기억된다. 위치에 따라 목록이 열리는 방향이 바뀐다.
  • 240px 이상 내려가면 옆에 '맨 위로' 버튼이 나타난다.

알림센터

  • 탭 5개: 전체(최근 3일) · 메모 · 공지사항 · 일정 · 시스템. 탭마다 건수 배지.
  • 일정 탭은 2026년 6월 달력이고, 일정 있는 날짜를 누르면 그날 일정만 남는다.
  • [모두 읽음]은 지금은 창만 닫는다. GNB의 안 읽은 개수는 줄지 않는다 데모

화면 이동과 상태

  • 모든 화면은 주소 #/route를 가진다. 북마크·직접 입력으로 열 수 있고, 주소 없이 열면 마지막으로 본 화면이 복원된다(처음이면 디자인 시스템).
  • 옛 한글 주소나 이름이 바뀐 주소는 새 주소로 자동 연결된다.
  • 화면을 옮길 때마다 0.5초 로딩 골격(+스피너)이 보이고, 스크린리더에는 '○○ 페이지 열림'을 알린다.
  • 운영체제의 '동작 줄이기' 설정을 따른다(부드러운 스크롤·확대 애니메이션 끔).

키보드 단축키

표시는 Mac 기준(⌘ = Windows Ctrl, ⌥ = Windows Alt). ⌥ 조합은 입력칸에 글자를 치는 중에는 동작하지 않고, ⌘ 조합은 입력 중에도 동작한다. 키를 누르고 있어도 한 번만 실행된다. 버튼에 마우스를 올리면 툴팁에 단축키가 함께 보인다. 리스트 화면의 등록·내보내기·인쇄(⌘⏎ · ⌥D · ⌘P)는 상세필터 드로어나 팝업(모달·확인창)이 열려 있는 동안 쉰다 — 이때 ⌘P는 브라우저 기본 인쇄(화면 전체)로 동작한다.

리스트 화면 공통 기능

스키마 화면은 아래 기능이 그대로 적용되고, 전용 화면도 대부분 같은 틀을 쓴다. 화면 카드에는 이 공통 동작과 다른 점만 적었다.

툴바

  • 왼쪽: 필터 표지(깔때기), 화면에 따라 기본 필터 칩(예: 심사단계·등급), 적용된 필터 칩. 적용 칩은 값만 보이고(마우스를 올리면 항목명이 툴팁으로 뜬다. 필터를 걸면 새로 걸린 칩에 3초간 저절로 뜬다) ×로 하나씩 지운다. 칩의 값을 누르면 상세필터가 열리며 그 항목으로 이동한다(바로 값을 바꿀 수 있게 초점이 그 칸에 간다). 2개 이상이면 [전체 해제], 넘치면 '+N' 메뉴로 접힌다.
  • 오른쪽: 금액 단위(원·백만원·억원, 해당 화면만), [상세필터], [○○ 등록](입력 항목이 있는 화면만), 조회(⟳).

표(그리드)

  • 행 선택은 왼쪽 체크박스로만 한다. 행을 클릭해도 선택되지 않는다. 머리 체크박스는 필터된 행 전체를 선택한다.
  • 행 더블클릭 또는 Enter → 수정 모달(입력 항목이 있는 화면).
  • 파란 글씨 셀은 링크다. 누르면 읽기전용 상세 팝업(월간보고 상세·운용사 명세·관리보수 상세·실사 체크리스트·정량지표 상세 등)이 열린다.
  • 우클릭 메뉴: 상세조회 · 수정 · 행 복사(탭 구분 텍스트) · Excel 내보내기 · 삭제(화면에 따라 일부).
  • 열 머리를 눌러 정렬. 2단 그룹 머리, 하단 합계 행, 셀 안 선택(확정/미확정 등)은 화면 정의에 따라 붙는다.
  • 정렬 규칙: 금액·비율·건수·인원 같은 수량은 오른쪽, 그 밖(No·연도·날짜·코드·상태)은 왼쪽.
  • 0건이면 '표시할 항목이 없습니다' 같은 빈 상태 문구가 보인다.

선택 바

  • 체크하면 툴바가 'N건 선택됨 · [수정](1건일 때) · [확정/미확정 일괄](해당 열이 있을 때) · [삭제] · [선택 해제]'로 바뀐다.
  • 스크롤해서 툴바가 가려지면 같은 버튼 묶음이 선택한 행 바로 위에 떠서 따라온다.
  • 상세필터나 필터 칩으로 조건을 바꾸면 선택이 모두 해제된다 — 걸러져 안 보이는 행에 수정·삭제가 걸리지 않게 하고, 툴바도 필터 칩 줄로 돌아온다. 선택한 행을 수정하거나 단계를 바꿔 걸어 둔 조건에서 벗어날 때도 같은 이유로 선택이 모두 해제된다. 다른 페이지로 넘어가는 것만으로는 선택이 풀리지 않는다.

푸터(하단 고정)

  • '총 N개 중 M개 항목 표시 중', 페이지 번호(20건 단위).
  • 오른쪽 버튼 4개: 전체보기(한 페이지에 모두) · 새 창 · 내보내기(엑셀) · 인쇄. 출력양식이 있는 화면은 인쇄가 버튼 그룹(🖨 | ▾)으로 바뀐다 — 아래 '인쇄·출력' 참조.

인쇄·출력

그리드만 인쇄 — 푸터 인쇄(🖨) 버튼과 ⌘P 모두 같은 동작이다.

  • 표(그리드) 부분만 찍는다. GNB·LNB·위치 경로·카드 머리(제목·KPI)·툴바·푸터·알림은 인쇄물에서 빠진다. 표 안에 있는 섹션 제목·탭은 함께 찍힌다.
  • 가로 스크롤 밖에 있던 열까지 표의 모든 열을 찍는다. 왼쪽 고정 열은 본문에 합쳐져 한 표로 나오고, 합계 행도 열 위치가 맞게 찍힌다.
  • 선택 체크박스 열은 데이터가 아니라서 빼고 찍는다.
  • 페이지로 나뉜 표는 지금 보고 있는 페이지의 행만 찍힌다. 모든 행을 찍으려면 먼저 푸터 [전체보기](⌥A)를 누른다.
  • 표가 용지보다 넓으면 용지 폭에 꽉 맞게(오른쪽 여백 없이) 자동으로 줄인다. 용지보다 좁은 표는 확대하지 않는다. 용지 폭별 비율을 미리 계산해 두므로, 인쇄 창에서 용지 크기·방향·여백을 바꾸면 미리보기도 거기에 맞게 다시 맞춰진다.
  • 모든 열이 다 그려진 뒤에 인쇄 창이 열린다(최대 5초 대기). 인쇄 창을 닫으면 화면은 원래대로 돌아온다(체크박스 열·고정 열·스크롤 표 복원). 인쇄 버튼을 연달아 눌러도 한 번만 인쇄한다.
  • 표 여러 장을 쌓은 화면은 그 표들을 모두 찍는다. 표 틀(GridFrame)이 없는 화면(대시보드 등)은 종전처럼 페이지 전체를 찍는다.
  • 적용 범위: 표 틀을 쓰는 모든 리스트 화면 — 스키마 화면 전부, 조기경보·수탁보고·부처보고 공용 화면 틀, 전용 화면 약 40개.

인쇄는 항상 라이트 테마 — 다크 모드로 보고 있어도 종이에는 라이트 색으로 찍힌다.

  • 그리드 인쇄, 대시보드 등의 페이지 전체 인쇄, 브라우저 메뉴 인쇄, 팝업 [출력]에 모두 적용된다.
  • 인쇄 창을 닫으면 화면은 다시 다크로 돌아온다. 저장된 테마 설정(⌥T)은 바뀌지 않는다.

팝업 [출력] — 팝업 안의 [출력] 버튼도 페이지 전체가 아니라 팝업 본문만 찍는다. 폭 맞춤·라이트 테마 규칙은 그리드 인쇄와 같다.

  • 현재 적용: 조기경보 › 운용사별 조기경보 조회 › 운용사 재무정보 팝업. 재무정보·손익정보·정량지표·기준년월별 추이·지표등급 변경정보 5개 섹션만 찍는다.
  • 팝업 제목줄·금액 단위 전환 버튼·하단 버튼·팝업 뒤 화면은 빠진다. 금액은 화면에서 고른 단위(원·백만원·억원)로 찍히고, 섹션 제목 옆 단위 표기도 함께 나온다.
  • 인쇄 창을 닫으면 팝업은 원래 위치·크기로 돌아온다.

출력양식 버튼 그룹 — 화면 전용 출력양식이 있으면 푸터 인쇄 버튼이 두 칸짜리 버튼 그룹이 된다.

  • 왼쪽 칸(🖨) = 그리드 인쇄(위와 같음, ⌘P도 이것). 오른쪽 칸(▾) = 그 화면의 출력양식 목록.
  • 목록에서 양식을 고르면 양식별 출력 팝업(출력 범위·대상 확인 등)이 열린다. 이 팝업의 [출력]은 아직 안내 메시지만 띄운다(데모 동작 — 실제 양식은 찍지 않는다).
  • 출력 메뉴는 툴바에 따로 두지 않고 이 푸터 버튼 그룹 한 곳에만 둔다(2026-09-24 결정).
  • 현재 적용: 등록원부관리 — ▾ '등록원부 출력'(페이지 범위 입력) · '등록원부 발급이력 출력'(조합명 확인).
  • 다른 화면은 출력양식이 생기면 같은 버튼 그룹의 ▾ 항목만 추가하면 된다(리스트 화면 틀과 조기경보·수탁보고·부처보고 공용 화면 틀 모두 같은 자리를 쓴다). 양식이 없는 화면은 인쇄 버튼 하나만 보인다.

구성 툴바 [상세필터]·[+ 전표 등록 │ ▾ 전표 업로드]·조회 · 기간 칩(기본 전월 1일 ~ 오늘) · 표 1장(선택 + 계정구분·전표일·순번·적요·금액·거래처·결재·첨부·작성자·전표발생구분·전표번호·자금집행예정일·최초등록자·최종수정자) · 상세필터 9항목 · KPI 없음 · 데모 16건

전용
#/acct-fixed-asset · ACC-017 · acc/fixedasset/fixed_asset_manage.tsx

유무형자산을 등록·수정·삭제하고, 처분·불용 변동을 기록하고, 취득·처분 전표를 계정구분별로 만든다.

구성 툴바 [상세필터]·[+ 유무형자산 등록](총괄 탭)·조회 · 기준년월 칩(기본 당월) · 탭 2개(총괄 · 변동내역) · 표 1장(총괄 19열 / 변동내역 15열 — 계정구분 > 자산유형 그룹, 그룹 끝 (계) 소계, 맨 아래 합계) · 상세필터 6항목 · KPI 없음 · 데모 자산 15건·변동 5건

  • 총괄 수량·잔존가액·자산상태는 기준년월 말까지의 변동을 반영해 보인다. 잔존가액 = 취득원가 − 감가상각누계액 − 처분·불용으로 줄어든 금액. 남은 수량이 0이면 자산상태가 처분/불용이 된다.
  • 계정구분·자산유형은 같은 그룹이 이어지면 첫 행에만 보이고(다음 쪽 첫 행에는 다시 보인다), 그룹마다 (계) 소계 행이 붙는다. 엑셀에는 모든 행에 값이 채워진다. 합계·소계는 금액 열(총괄: 취득원가·전기말장부가액·전기말상각누계액·감가상각누계액·잔존가액 / 변동내역: 처리수량·매각액·취득가감소액)만 더한다. 소계·합계 행은 고를 수 없다.
  • 상세필터: 기준년월*(기본 당월, 비울 수 없음) · 계정구분 · 자산유형(계정구분에 따라 좁혀짐) · 자산번호 · 자산명(부분일치) · 취득기간. 값을 바꾸는 즉시 목록과 칩에 반영되고 [필터 적용]은 창만 닫는다. 취득기간 시작이 종료보다 늦으면 그 칸에 '취득기간을 확인해 주세요.'가 뜨고 기간 조건만 빠진다. 기준년월 칩의 ×는 당월로 되돌린다.

  • [삭제]는 조건 밖 건이 하나라도 섞이면 전체를 멈춘다 — '전표가 생성된 자산은 삭제할 수 없습니다.' / '변동내역이 있는 자산은 삭제할 수 없습니다.'. 변동내역 삭제는 수량·잔존가액을 원래대로 돌리며, 전표가 생성된 변동과 같은 자산의 나중 변동이 남은 변동은 지울 수 없다.
  • 「유무형자산관리」 등록/수정(행 더블클릭·Enter): 자산정보·관리정보 2구역. 취득원가(구입가액 + 부대비용)·잔존가액·상각률(정액 1/n · 정률 1 − 0.05^(1/n))은 자동. 자산번호는 취득일 + 같은 날 일련번호 4자리로 채번된다. 저장 때 계정구분·자산유형·자산명·구입가액·수량과 단가·취득구분·취득일자·상각구분 순으로 검사하고 걸린 칸을 빨간 테두리로 표시한다. 구입가액 0원은 미입력으로 보고, 내용년수는 1~99년만 받는다. 전표가 생성됐거나 변동내역이 있는 자산은 계정구분·자산유형·금액·수량·취득일자를 고칠 수 없다. 취득일자를 바꾸면 자산번호가 새 날짜로 다시 매겨지고, 기준년월 이후 날짜면 '목록에 표시되지 않습니다' 안내가 뜬다 데모
  • 「변동 등록」: 변동구분(처분/불용)·변동일(취득일·같은 자산의 최근 변동일 이전 불가)·처리구분(전체 = 남은 수량 전부/부분)·처리수량·매각액(불용은 0). 취득가액 감소액 F = 미상각잔액 ÷ 잔여수량 × 처리수량, 처분손익 H = D − E − G + F 를 자동으로 보인다(전표 분개의 처분손익은 장부가 − 매각액이라 H 와 다를 수 있다 — 산식 확정 전).
  • [전표생성]: 선택 중 전표가 없는 건만 계정구분별로 전표 1건씩 만든다(이미 생성된 건은 'N건은 제외됩니다' 안내). 탭마다 전표일자·적요(기본 '유무형자산 취득 — 계정구분 · 자산명 외 N건')와 분개 미리보기(취득 = 차) 자산유형 계정 / 대) 미지급금, 처분·불용 = 차) 감가상각누계액·현금·처분손실 / 대) 자산유형 계정·처분이익)를 확인한다. 모든 탭 차대가 맞아야 [생성]이 켜지고, 생성되면 전표번호와 결재상태 '미상신'이 붙는다 데모
  • 전표번호 셀을 누르면(또는 Enter) 일반전표 관리로 이동한다. 푸터: 새 창 · 내보내기 ⌥D(현재 탭 · 소계·합계 포함) · 인쇄.

  • [계정과목 설정](툴바, [저장] 오른쪽): 자산유형 5종(건물·차량운반구·집기비품·시설장치·소프트웨어)별 차변·대변 계정을 2단 머리 표에서 [검색] → 계정과목 검색으로 고른다(계정코드는 자동). 저장하지 않고 닫으면 확인을 묻는다.

전용

  • 첫 화면은 당해년도·당월 달력이다. 상세필터는 없고, 년·월은 툴바의 월 선택으로 고른다(가운데 'YYYY년 M월'을 누르면 년도를 넘겨 달을 고르는 창 — 당해년도 ±5년). 목록·달력 모두 항상 한 달을 보여 준다 데모
  • ‹ › 는 한 달씩 옮기며 연도를 넘어간다(1월 ‹ = 전년 12월, 12월 › = 다음해 1월). 선택 범위 양 끝 달에서만 꺼진다. [오늘]은 당해년도·당월로 돌아간다. 보기를 바꿔도 년·월은 유지된다.
  • 달력: 일요일 시작 7열, 머리글 요일색(일 빨강·토 파랑). 등록 휴일 칸은 날짜 빨강 + 연한 빨강 배경 + 휴일명 + 짧은 구분(법정/대체/임시/기타), 사용자가 등록한 휴일(등록자 ≠ 시스템)은 구분 앞에 [사용자] 태그. 오늘 칸은 굵은 테두리 + '오늘'. 등록 휴일 칸을 누르면(또는 Enter·Space) 목록 행 더블클릭과 같은 「휴일 수정」 창이 그 휴일 값으로 열린다 — 저장·삭제는 목록과 같고 저장 뒤에도 달력에 머문다. 휴일 없는 날 칸은 클릭 동작이 없다(빈 날 클릭 등록은 설계서 미결).

  • 「휴일 등록」(⌘⏎) / 「휴일 수정」(행 더블클릭·Enter · 선택 바 [수정] · 달력 휴일 칸 클릭): 일자*·휴일명*(30자)·휴일구분*(법정공휴일·대체공휴일·임시공휴일·기타휴일, 기본 미선택)·비고(100자)·등록자(읽기 전용 — 신규는 로그인 사용자, 수정은 기존 유지). 저장 때 일자 → 일자 범위(당해년도 ±5년 — 툴바 월 선택 범위와 같다) → 일자 중복('이미 등록된 일자입니다', 수정은 자기 자신 제외) → 휴일명 → 휴일구분 순으로 첫 미충족 칸을 빨간 테두리·문구·토스트로 알린다. 저장하면 그 일자의 년·월로 이동하고 목록이면 그 행을 선택한다 데모
  • 입력하거나 바꾼 내용이 있는 채로 ✕·Esc·[취소]를 누르면 '작성 중인 내용이 사라집니다' 확인([계속 작성]/[닫기])을 거친다. 푸터: 새 창 · 내보내기 ⌥D(보고 있는 달 — 파일명 휴일관리_YYYY-MM) · 인쇄 · 전체보기(목록).
