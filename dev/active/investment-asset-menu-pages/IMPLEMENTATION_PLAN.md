# 투자자산관리 메뉴 페이지 — 구현 계획 (Designer 권고 반영)

- 책임 역할: Developer
- 실행 환경: Orca managed worktree + Claude Code
- 기준 설계: `DESIGN_RECOMMENDATION.md` (2026-09-15)
- 이 문서는 `BRIEF.md`의 "13개를 모두 신규 전용 페이지"라는 초기 가정보다 우선한다.

## 정정된 현황

- 이미지 범위는 19개 리프이며, 자펀드 관리 6개는 이미 전용 React 페이지로 구현되어 있다.
- 나머지 13개는 `GenericListPage`를 쓰지만, 10개는 route 전용 `PageSchema`가 이미 있다.
- 실제 `DEFAULT_SCHEMA` 공백은 정확히 3개다.
  1. `투자기업명세서(통합)`
  2. `우수투자기업 관리`
  3. `운용사 명세서`

따라서 목표는 복제성 높은 13개 전용 컴포넌트가 아니라, **기존 APFS 스키마 기반 화면을 HTML 목업 기준으로 완성하고 3개 공백을 결선**하는 것이다. 이 방식이 기존 운영 UI의 공통 필터·GridFrame·AG Grid·상세/모달 규약을 지킨다.

## 구현 순서 (TDD)

### 1. route/schema 결선 테스트 — RED

- 13개 라우트 키를 리터럴로 테스트한다.
- 각 키가 `DEFAULT_SCHEMA`가 아닌 스키마를 해석하고, 제목/브레드크럼이 이미지 메뉴와 일치해야 한다.
- 이 테스트가 현재 3개 공백에서 예상대로 실패하는 것을 기록한다.

대상 리터럴:
- `투자기업정보(통합)`, `투자기업명세서(통합)`, `투자기업 고용현황보고`, `전체 투자실적`, `투자실적 현황(투자기업)`, `투자금 회수현황`, `우수투자기업 관리`
- `운용사 명세서`, `운용사 재무정보 조회`, `투자금 실사보고`, `사후관리기록 관리`, `관리보수관리`, `전체 보고현황`

### 2. 공통 금액 단위 토글 — GREEN

- `PageSchema`에 opt-in 단위 토글 메타데이터를 최소 범위로 추가한다.
- `GenericListPage`의 툴바 우측에만 `원 / 백만원 / 억원` `SegTabs`를 렌더한다.
- 금액 타입 컬럼만 환산하고, 화면 단위·Excel 내보내기 단위를 같은 상태로 사용한다.
- 마스킹은 값만 `mn()` 경계를 지키며 UI chrome은 마스킹하지 않는다.
- 대상: 투자기업정보(통합), 투자기업명세서(통합), 고용현황, 전체 투자실적, 투자실적현황(투자기업), 투자금 회수현황, 우수투자기업 관리, 운용사 재무정보 조회, 전체 보고현황 및 운용사 명세 팝업.

### 3. 공백 3개 스키마/상세 결선

1. **투자기업명세서(통합)**
   - `S1_31` 기반의 5개 컬럼 그룹(기본/대표자/기업식별/투자·회수/재무)과 와이드 내부 스크롤.
   - 고정 좌측 열: 운용사·자펀드·투자기업.
   - 읽기 전용, 58 컬럼 Excel 내보내기 중심. 페이지 전체 가로 스크롤 금지.
2. **우수투자기업 관리**
   - 신규 제안 화면으로 provenance를 `NEW`로 남긴다. `sample`에 출처가 있는 것처럼 보이는 리터럴 행을 넣지 않는다.
   - 선정연도/등급/운용사/자펀드/사업분야/사후관리 상태 필터, 등록·수정·삭제 목업 흐름, 선정 근거/상태 텍스트 배지.
   - `최우수/우수/후보` 등의 등급은 제안된 더미 도메인임을 코드 주석/설계 문서에서만 분명히 하고, 실제 제도처럼 확정하지 않는다.
3. **운용사 명세서**
   - 브리프의 S1_37 대신 실제 명세 출처 `S1_02_운용사_명세.html`을 읽기 전용 근거로 채택한다.
   - 목록 + 행 Enter/더블클릭 + 선택행 툴바 명세 버튼으로 `GpSpecModal`을 연다.
   - `GpSpecModal`의 row prop은 optional로 확장해 기존 `occasional_report_manage.tsx` 호출을 보존한다.
   - `S1_37_운용사별_재무제표` orphan 스키마는 삭제하거나 라우팅하지 않는다.

### 4. 기존 10개 스키마 보정

- 투자기업정보(통합): 운용사/자펀드/계정구분 필터, `S1_30` 기업개요 상세 팝업, 카드뷰/KPI 제거.
- 투자기업고용현황(통합): 담당자/업로드여부 필터, 업로드 상태와 단위 토글.
- 전체 투자실적: 누락 6개 컬럼·원문 `!` 검토 마커·통계기준 추가.
- 투자실적현황(투자기업): 현 소재지별 집계 화면을 유지한다. 3축 SegTabs 전용 구현은 별도 후속 범위로 명시한다.
- 투자금 회수현황: S1_35 출처를 유지하며, S1_36 거래내역은 행 상세/드릴다운으로만 재사용한다.
- 운용사 재무정보 조회: 그룹 컬럼, 단위 토글, 조회 전용 동작 유지.
- 투자금 실사보고 조회: 담당자/보고여부 필터와 확정 상태만 보강한다. 비어 있는 체크리스트 상세는 만들지 않는다.
- 사후관리기록 관리: S1_42 provenance, 투자기업 용어, 검색 축, 문서 첨부와 기존 CRUD 규약을 보강한다.
- 관리보수/성과보수 조회: 페이지 제목은 메뉴 라벨로 맞춘다. 원본에 없는 성과보수 컬럼을 창작하지 않는다.
- 자펀드 전체 보고현황: 전용 `GridFrame` 안에서 `투심 / 수시보고 / 조합원총회` 3개 표를 SegTabs로 전환하고 결과 건수를 aria-live로 알린다.
